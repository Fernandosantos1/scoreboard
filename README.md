# scoreboard
⚽ Scoreboard App: Um placar esportivo minimalista e intuitivo desenvolvido com React Native e Expo. Interface dividida (azul/vermelha) com gestos para controle de pontuação, timer integrado e suporte a múltiplas orientações. Ideal para esportes, competições, eventos ou qualquer atividade que precise de um placar simples e eficiente.
